# DSE UI

A registry of React components for DSE web applications, built on [Base UI](https://base-ui.com) and Tailwind CSS v4 and distributed with the [shadcn CLI](https://ui.shadcn.com/docs/registry).

> **Status: experimental.** Components, names and documentation may change without notice.

## How it works

This isn't an npm package. When you add a component, the shadcn CLI **copies its source code into your project**:

```bash
npx shadcn@latest add aryanmehta-gnrc/ui-registry/button
```

The copy belongs to your project from then on. That means:

- You can read and change everything; nothing is hidden in `node_modules`.
- Updates don't arrive automatically. Re-install a component to pick up fixes (see **Getting Started › Updating**).
- The CLI also installs the npm packages and other registry components it depends on.

Each component has a **Docs** page (usage guidance, accessibility notes, the props table and every example) and individual **stories** you can open and adjust with the controls.

## Principles

1. **Accessible by default.** Every component targets WCAG 2.2 AA and is tested for it automatically.
2. **Theme tokens, never hard-coded colours.** Components follow whichever theme your project uses.
3. **Works in any React setup.** Vite, Next.js, and Symfony through React islands.
4. **Documented next to the code.** Each component's docs live beside its source, so they change together.
